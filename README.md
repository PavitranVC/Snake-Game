# Snake Game (Neon Snake)

A neon 2D snake arcade game built with Vite, React and Phaser 3: Slither.io-style steering, boost, AI snakes, powerups, a 3-level campaign, a leaderboard and Perlin-noise terrain.

```
npm install
npm run dev
```
